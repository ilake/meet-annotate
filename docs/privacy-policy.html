Privacy Policy

Annotate Together — Last updated: March 2026

Overview

Annotate Together is a collaborative drawing tool for web browsers. We are committed to protecting your privacy. This extension collects the minimum data necessary to provide real-time annotation features.

Data We Collect

Annotate Together collects and transmits only the following data:

  • Drawing data: Stroke coordinates, colors, widths, and tool types
  • Anonymous user ID: A randomly generated identifier stored in your browser's localStorage (e.g., "u-abc123-xyz789"). This is NOT linked to your identity.
  • Page URL hash: A numeric hash of the current page URL is used to create a shared "room." The actual URL is not stored.

Data We Do NOT Collect

  • Personal information (name, email, address)
  • Browsing history
  • Page content or screenshots
  • Cookies or login credentials
  • Analytics or usage tracking data

How Data Is Used

Drawing data is sent to Firebase Realtime Database (hosted by Google) solely for the purpose of synchronizing annotations between users viewing the same page. Data is used for no other purpose.

Data Retention

  • Drawing data is temporary and is automatically deleted when users leave the page.
  • Any remaining data expires and is cleaned up within 1 hour.
  • No long-term data storage occurs.

Third-Party Services

This extension uses Firebase Realtime Database (by Google) for real-time data synchronization. Firebase's privacy policy can be found at firebase.google.com/support/privacy.

No other third-party services, analytics tools, or advertising networks are used.

Permissions

  • activeTab: Required to detect the current page for annotation overlay.
  • scripting: Required to inject the annotation canvas and toolbar into web pages.
  • Host permissions (Firebase): Required to sync drawing data between users in real-time.

Data Security

All communication with Firebase uses HTTPS encryption. No authentication is required to use the extension — room access is based on the page URL hash, which provides basic isolation between different pages.

Children's Privacy

This extension does not knowingly collect any personal information from children under 13.

Changes to This Policy

We may update this privacy policy from time to time. Changes will be reflected in the "Last updated" date above.

Contact

If you have questions about this privacy policy, please open an issue on our GitHub repository or contact us through the Chrome Web Store listing.
